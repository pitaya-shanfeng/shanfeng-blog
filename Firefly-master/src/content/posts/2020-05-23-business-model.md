## 一、如何描述商业模式

任何关于商业模式创新的讨论、会议及研讨的起点都应该是基于对一个商业模式本质的共识性的理解，商业模式并非单指盈利模式，它应该涵盖一个商业体的四个主要部分：客户、产品或服务、基础设施及金融能力，一个商业模式描述的是一个组织创造、传递以及获得价值的基本原理。商业模式就像是一幅战略蓝图，可以通过组织框架、组织流程及组织系统来实施。

我们需要一种统一的语言，用以直观地描述、评估并改变一个商业模式，商业模式画布便是这样一种通用语言，让我们得以简单的描述商业模式以创造新的战略选择，在商业模式画布的描述下，商业模式共包含九大模块，这九大模块可以展示出一家公司寻求利润的逻辑过程，九大模块分别为：客户细分、价值主张、渠道通路、客户关系、收入来源、核心资源、关键业务、重要伙伴，以及成本结构。

### 1.1 客户细分（CS）

#### 1、概念

客户是任何一个商业模式的核心，没有可以带来利润的客户，没有哪家企业可以一直存活下去。为了更好地满足客户，企业应该按照他们的需求、行为、特征的不同，将客户分成不同的群组。一个商业模式可以服务于一个或多个或大或小的客户群体，但一个组织需要谨慎选择服务哪个客户群体以及忽略哪个客户群体，这一点得到确定，就要根据对这些群体个性化需求的深度理解去设计商业模式。细分客户群体的条件：

- 他们的需求催生了一项新的供给
- 需要建立一个新的分销渠道
- 需要建立一套新的客户关系类型
- 他们产生的利润率显著不同
- 他们愿意为某方面的特殊改进而买单

#### 2、客户细分方式

| <span style="display:inline-block;width:120px">细分方式</span> | 解释                                                         | <span style="display:inline-block;width:120px">案例</span> |
| :----------------------------------------------------------- | :----------------------------------------------------------- | :--------------------------------------------------------- |
| 大众市场                                                     | 基于大众化市场的商业模式不会区分客户群体，他们的价值主张、分销渠道、客户关系聚焦于一个庞大且拥有广泛相似需求和问题的客户群。 | 手机、电脑等消费电子产品                                   |
| 小众市场                                                     | 目标为小众市场的商业模式迎合的是某一个具体的客户群体，他们的价值主张、分销渠道、客户关系皆是根据某一小众市场的具体需求量身打造的。 | 芯片、汽车零件等配件产品                                   |
| 求同存异的客户群体                                           | 有的商业模式面向的是有些许区别需求和问题的多个细分市场，这样的客户群体有着相似却不同的需求和问题，对于每个客户群体都提供稍微有区别的价值主张、分销渠道、客户关系等。 | 银行、理财平台等金融服务产品                               |
| 多元化的客户群体                                             | 一个面向多元化客户群体的组织服务的是两个需求和问题迥异的客户群体。 | 阿里、亚马逊的零售业务包含普通商品、云服务等               |
| 多边平台的客户群体                                           | 有的组织服务的是两个或者多个相互独立的客户群体。             | 团购、外卖、信用卡等生活服务                               |

### 1.2 价值主张（VP）

#### 1、概念

价值主张是客户选择一家公司而放弃另外一家的原因，它解决了客户的问题或满足其需求。每一个价值主张就是一个产品或服务的组合，这一组合迎合了某一客户群体的需求。从这个意义上说，价值主张就是一家公司为客户提供的利益的组合。价值主张可以是一种新的或者是革命性的产品或服务，也可以是与现有产品或服务相似，但是有了新的特点和属性。

#### 2、价值创造因素

一个价值主张通过针对某个群体的需求定制一套新的元素组合来为该群体创造价值，所创造的价值可以是数量上的，也可以是质量上的。

| <span style="display:inline-block;width:120px">因素</span> | 解释                                                         | <span style="display:inline-block;width:120px">案例</span> |
| :--------------------------------------------------------- | :----------------------------------------------------------- | :--------------------------------------------------------- |
| 创新                                                       | 有的价值主张满足的是客户之前未曾察觉的全新需求，因为之前并没有类似的产品或服务 | 手机的出现、投资基金的出现                                 |
| 性能                                                       | 改进产品或服务的性能是一项传统而且普遍的创造价值的方式       | 5G的研发、电脑的计算速度的研发                             |
| 定制                                                       | 针对某些客户群体的某项需求提供定制的产品或服务能够创造价值   | 旅游方案定制、乐高玩具定制                                 |
| 保姆式服务                                                 | 简单地帮助客户完成任务也可以创造价值                         | O2O服务、汽车4S店                                          |
| 设计                                                       | 一个产品可能由于其出色的设计而鹤立鸡群                       | 服饰、花艺                                                 |
| 品牌地位                                                   | 客户可以简单地通过使用和展示某一品牌而获得价值               | 奢侈品、潮牌                                               |
| 价格                                                       | 以更低的价格提供相同的价值是满足价格敏感型客户群体的需求的普遍方式 | 低价机票、租车服务、免费新闻资讯                           |
| 缩减成本                                                   | 帮助客户节约成本是创造价值的重要方式                         | 网盘、云服务                                               |
| 风险控制                                                   | 为客户购买的产品或服务降低风险，能够为其创造价值             | 7天无理由售后、保修政策                                    |
| 可获得性                                                   | 帮助客户获得之前他们无法获得的产品和服务也是创造价值的方式   | 购买飞机、游艇                                             |
| 便利性/实用性                                              | 让产品使用起来更方便或操作起来更简单也可以创造相当大的价值   | 汽车一键启动；苹果iPod                                     |

### 1.3 渠道通路（CH）

#### 1、概念

与客户的交流、分销和销售渠道构成了一个企业的客户交互体系，渠道通路在客户体验中扮演着重要角色的客户触点。渠道通路的作用包括：

- 使客户更加了解公司的产品或服务
- 帮助客户评估一家公司的价值主张
- 使得客户得以购买某项产品或服务
- 向客户传递价值主张
- 向客户提供售后支持

#### 2、渠道的类型与阶段

每一个渠道都可以划分为五个相互独立的阶段，每个渠道都覆盖了其中几个或者全部五个阶段。我们可以把渠道划分为直接和间接的渠道，或者划分为自有和合作方的渠道。要将一种价值主张推向市场，找到正确的渠道组合并以客户喜欢的方式与客户建立起联系显得至关重要。一个组织可以选择自有渠道来与它的客户建立联系，也可以选择合作方的渠道或者两者兼用。自有渠道可以是直接的，比如销售团队或自有网站；也可以是间接的，比如旗下的自有商铺；合作方渠道是间接的，并且范围比较广，比如批发分销、零售门店、合作方运营的网站。使用合作方的渠道导致利润更低，但是这些渠道可以帮助一个组织扩张客户的范围，并且从合作方的强项中获益；使用自有渠道利润较高，但是同时建立和运营渠道的成本也很高。

| <span style="display:inline-block;width:120px">渠道类型</span> | 具体渠道（举例） | 渠道属性 |
| :----------------------------------------------------------- | :--------------- | :------- |
| 自有渠道                                                     | 销售人员         | 直接     |
|                                                              | 自有网站         | 直接     |
|                                                              | 自有商铺         | 间接     |
| 合作方渠道                                                   | 合作方商铺       | 间接     |
|                                                              | 合作商批发       | 间接     |
|                                                              | 合作方网站       | 间接     |

| <span style="display:inline-block;width:120px">渠道阶段</span> | 描述                                     |
| :----------------------------------------------------------- | :--------------------------------------- |
| 知名度                                                       | 我们如何扩大公司产品和服务的知名度？     |
| 评价                                                         | 我们如何帮助用户评价我们的价值主张？     |
| 购买                                                         | 客户如何能够购买到我们的某项产品和服务？ |
| 传递                                                         | 我们如何向客户传递我们的价值主张？       |
| 售后                                                         | 我们如何向客户提供我们的售后支持？       |

### 1.4 客户关系（CR）

#### 1、概念

企业需要明确：对每一个客户群体欲建立何种关系类型，从靠人员维护客户关系，到自动化设备与客户间的交互，都属于客户关系范畴。客户关系可能有以下动机驱动：

- 开发新的客户
- 留住原有客户
- 增加销售量或销售单价

#### 2、客户关系类型

由商业模式决定的客户关系将对整体的客户体验产生深刻影响，客户关系可以分为几种类型，这些类型可能同时存在于企业与某个客户群体的客户关系中。

| <span style="display:inline-block;width:120px">类型</span> | 解释                                                         | 案例                            |
| :--------------------------------------------------------- | :----------------------------------------------------------- | :------------------------------ |
| 私人服务                                                   | 基于人际互动，客户可与客户代表进行交流并在销售过程中以及购买完成后获得相应的帮助 | 汽车、房产销售、售前售后客服    |
| 专属私人服务                                               | 要求为每一个客户指定一个固定的客户经理，这是一种最深层、最私人的客户关系类型，通常需要很长时间的积累 | 私人理财顾问、私人律师          |
| 自助服务                                                   | 企业无须直接维护与客户的关系，企业只要为客户提供一切自助服务所需要的渠道 | 自助取票机、自助办理柜台、ATM机 |
| 自助化服务                                                 | 将相对复杂的客户自助服务形式与自动化流程相结合               | 电影推荐、商品推荐、内容推荐    |
| 社区                                                       | 用户社区可用来融入客户以预判市场未来发展方向，同时也需要促进社区中成员的联系 | 米粉社区、微淘                  |
| 协作创造                                                   | 更多的企业开始超越传统的买卖关系，与客户合作共同创造价值     | 抖音、人人都是产品经理          |

### 1.5 收入来源（R$）

#### 1、概念

如果说客户构成了一个商业模式的心脏，那么收益来源便是该商业模式的动脉。一家企业需要自问，每一个客户群体真正为之买单的究竟是什么？成功地回答这一个问题可以使得企业在每一个客户群体中获得一两个收益来源。每一个收益来源中可能包含不同的价格机制，比如固定目录价、议价、竞价、根据市场浮动的价格、根据购买数量浮动的价格。一个商业模式可能包含的收益来源分为以下两种不同的类型：

- 交易收入由客户一次性支付产生
- 因向客户传达了新的价值主张或提供了售后支持而带来的持续支付

#### 2、收入来源方式

| <span style="display:inline-block;width:120px">来源方式</span> | 描述                                                         | 案例                           |
| :----------------------------------------------------------- | :----------------------------------------------------------- | :----------------------------- |
| 资产销售                                                     | 实物产品所有权的出售（最普遍的）                             | 书籍、音乐、生活用品、电子产品 |
| 使用费                                                       | 对某种具体服务的使用所产生的，对该服务使用得越多，消费者支付的就越多 | 话费、快递、酒店               |
| 会员费                                                       | 通过向用户销售某项服务持续的使用权限实现                     | 健身卡、音乐影视会员           |
| 租赁                                                         | 将某一特定资产在某个时段内供给某人使用并收取一定的费用       | 共享汽车、共享充电宝           |
| 许可使用费                                                   | 向用户授予某种受保护知识产权的使用权，并向其收取许可使用费   | 专利、版权                     |
| 经纪人佣金                                                   | 来源于向双方或多方提供的中介服务                             | 房产、汽车中介、人才猎头       |
| 广告费                                                       | 为某种产品、服务或品牌做广告的费用                           | 搜索广告、传媒广告             |

#### 3、收入的定价机制

每一种收入来源可能有着不同的定价机制，定价机制的选择可能在所创造的收入的结果上产生巨大的不同，主要的定价机制分为：固定价格、浮动价格。

| <span style="display:inline-block;width:120px">定价机制</span> | <span style="display:inline-block;width:120px">定价类型</span> | 描述                                               |
| :----------------------------------------------------------- | :----------------------------------------------------------- | :------------------------------------------------- |
| 固定价格                                                     | 单价                                                         | 对个别产品、服务或其他价值主张设定的固定价格       |
|                                                              | 套餐价                                                       | 基于某项价值主张的数量和质量的定价                 |
|                                                              | 会员价                                                       | 基于某一客户群体的类型和特征的定价                 |
|                                                              | 批发价                                                       | 基于购买数量的定价                                 |
| 浮动价格                                                     | 议价                                                         | 双方或多方的价格谈判，取决谈判各方的谈判能力或技巧 |
|                                                              | 促销价                                                       | 价格取决于库存及发生购买的时间                     |
|                                                              | 市场价                                                       | 价格根据需求变化动态变动                           |
|                                                              | 竞价                                                         | 根据竞价的结果决定                                 |

### 1.6 核心资源（KR）

#### 1、概念

每一种商业模式都需要一些核心资源，这些资源使得企业得以创造并提供价值主张，获得市场，保持与某个客户群体的客户关系并获得收益，不同类型的商业模式需要不同的核心资源，例如一个芯片制造商需要的是资本密集型的生产设备，而芯片的设计则聚焦于人力资源。

核心资源可包括实物资源、金融资源、知识性资源以及人力资源，核心资源可以是自有的，也可以是通过租赁获得或者是从合伙伙伴中获得的。

#### 2、核心资源类型

| <span style="display:inline-block;width:120px">资源类型</span> | 描述                                                         | <span style="display:inline-block;width:120px">案例</span> |
| :----------------------------------------------------------- | :----------------------------------------------------------- | :--------------------------------------------------------- |
| 实物资源                                                     | 包括实物资产，如生产设备、房屋、车辆、机器、系统、销售点管理系统及分销渠道 | 大型商超、亚马逊、京东                                     |
| 知识性资源                                                   | 包括品牌、专营权、专利权、版权、合作关系及客户数据库         | 微软、高通                                                 |
| 人力资源                                                     | 知识密集型产业和创新产业中，人力资源往往是最关键的           | 在线外教                                                   |
| 金融资源                                                     | 有些商业模式依赖于金融资源或金融保障                         | 理财平台                                                   |

### 1.7 关键业务（KA）

#### 1、概念

每一个商业模式都有着一系列的关键业务，这些业务是一个企业成功运营所必须采取的最重要行动，同核心资源一样，他们是企业为创造和提供价值主张、获得市场、维护客户关系以及获取收益所必须的，关键业务也因不同的商业模式类型而不同。例如对于软件商而言，关键业务就是软件开发。

#### 2、关键业务类型

| <span style="display:inline-block;width:120px">业务类型</span> | 描述                                                         | <span style="display:inline-block;width:120px">案例</span> |
| :----------------------------------------------------------- | :----------------------------------------------------------- | :--------------------------------------------------------- |
| 生产                                                         | 涉及以较大的数量或上乘的质量，设计、制造以及分销产品         | 传统制造行业                                               |
| 解决方案                                                     | 涉及为个体客户的问题提供新的解决方案                         | 医院、咨询公司                                             |
| 平台网络                                                     | 在将平台作为关键资源的商业模式中，与平台以及网络相关的关键活动占据这支配地位。网络、配对平台、软件、品牌等都可以发挥平台作用 | 交易平台                                                   |

### 1.8 重要合作（KP）

#### 1、概念

有很多原因使得一家企业需要构建重要合作，而重要合作在许多商业模式中逐渐承担起基石的作用，企业通过建立联盟来优化自身的商业模式、降低风险或获得资源，重要合作分为以下四种不同的类型：

- 非竞争者之间的战略联盟
- 竞争者之间的战略合作
- 为新业务建立合资公司
- 为保证可靠的供应而建立的供应商与采购商的关系

#### 2、合作建立动机

| <span style="display:inline-block;width:120px">动机</span> | 描述                                                         | <span style="display:inline-block;width:120px">案例</span> |
| :--------------------------------------------------------- | :----------------------------------------------------------- | :--------------------------------------------------------- |
| 优化及规模效应                                             | 以优化资源以及活动的配置为目的，要一家公司拥有全部所需的资源并亲自完成所有的生产、服务环节并不合理 | 服务外包                                                   |
| 降低风险和不确定性                                         | 竞争环境以不确定为特征，合作关系的建立可以帮助企业在竞争环境中降低风险，互为竞争对手的企业在某个领域建立战略联盟，而在其他领域保持竞争关系的做法是很常见的 | 蓝光技术                                                   |
| 特殊资源及活动的获得                                       | 很少有公司拥有其商业模式下所需要的全部资源或者选择亲自完成所有的生产服务活动，更多情况下，他们通过依赖其他占有某项资源或专注于某种生产活动的公司来实现其能力的拓展。这种类型的合作关系的动机在于获得知识、获得某种资质或者接近某个客户群体 | 手机厂商搭载Android系统                                    |

### 1.9 成本结构（C$）

#### 1、概念

这个模块描述的是运营一个商业模式，所发生的成本总和，创造和传递价值、维护客户关系，以及创造收益都会发生成本。在确定了核心资源、关键业务以及重要合作的情况下，成本核算就会变得相对容易，尽管有些商业模式相对于其他商业模式而言更加成本导向化。

成本最小化是每一个商业模式的述求，但是低成本结构在某些商业模式中会显得尤其重要，因此可以将商业模式的成本结构宽泛的分为两个等级：成本导向型、价值导向型。

- 成本导向

成本导向的商业模式聚焦于最大限度的将成本最小化，这种方式的目标在于创造并维持精简的成本结构，采取的是低价的价值主张、自动化生产最大化以及广泛的业务外包，例如低价机票。

- 价值导向

有些企业在商业模式的设计中，更少关注成本，而更多关注价值创造，通常更高端的价值主张以及高度的个性化服务是价值导向商业模式的特点，例如豪华酒店。

#### 2、成本结构特点

| <span style="display:inline-block;width:120px">特点</span> | 描述                                                         | <span style="display:inline-block;width:120px">案例</span> |
| ---------------------------------------------------------- | ------------------------------------------------------------ | ---------------------------------------------------------- |
| 固定成本                                                   | 不因产品及服务的产量而改变的成本，包括员工工资、租金、生产设备 | 生产企业的租金支出                                         |
| 可变成本                                                   | 随着产品及服务的产量而同比例变化的成本                       | 生产企业的物料支出                                         |
| 规模经济                                                   | 企业的产出扩大，会带来成本优势，总产出的增加，平均单位成本降低 | 大企业的采购成本                                           |
| 范围经济                                                   | 企业的经营范围扩大，会带来成本优势                           | 手机零售商同时销售智能家居产品                             |

## 二、商业模式的主要类型

### 2.1 分拆商业模式

#### 1、概念

将企业从事的活动分为三种不同类型：客户关系管理、新产品开发、基础设施管理，每种类型的活动有着不同的经济、竞争、文化规则。这三种类型可能共存于同一家企业中，但理想状态下，它们各自存在于相互独立的实体中以避免冲突或不必要的消长。

| <span style="display:inline-block;width:120px"> </span> | 客户关系管理                                                 | 新产品开发                                       | 基础设施管理                                                 |
| ------------------------------------------------------- | ------------------------------------------------------------ | ------------------------------------------------ | ------------------------------------------------------------ |
| 解释                                                    | 找到和赢得客户并与它们建立关系                               | 开发新的、有吸引力的产品和服务                   | 建立并管理可处理大量的重复任务的平台                         |
| 经济规则                                                | 由于高昂的客户开发成本，导致需要从每个客户手中获取高份额回报，范围经济是关键 | 早期市场进入获得高溢价和大量市场份额，速度是关键 | 高固定成本使得高产量成为获得低单位成本的关键，规模经济是关键 |
| 竞争规则                                                | 范围之争：少量的大玩家主导市场                               | 能力之争：进入门槛低，大量小玩家争奇斗艳         | 规模之争：迅速固话的市场，少量大玩家主导市场                 |
| 文化规则                                                | 高度服务导向：顾客第一                                       | 以雇员为中心：呵护创意明星                       | 聚焦成本：强调标准化、可预期性和生产效率                     |

目前全世界已经有非常多的移动通信企业将他们部分网络运营及维护业务外包给一些设备生产商。设备生产商可以做到以更低的成本运行网络，因为他们可以同时为多个运营商提供服务从而享受规模经济所产生的收益。

**（2）内容提供商**

产品开发需要创新型的人才，对于吸引这类人才而言，小而有活力的组织通常做得更好，运营商与多个第三方的内容提供商合作，保证了不断有新的技术、服务和媒体内容补充进来，比如地图、游戏、视频、音乐等。

**（3）通信运营商**

将基础设施管理业务和新产品开发业务减掉后，运营商得以更专心的聚焦于品牌管理以及细分客户群体的服务商，运营商专注于客户，并增加现有用户的购买量，利用多年来的投资获取客户以及维系客户。

### 2.2 长尾商业模式

#### 1、概念

长尾商业模式在于少量多种地销售自己的产品：它致力于提供相当多种类的小众产品，而其中的每一种卖出量相对很少。将这些小众产品的销售汇总，所得收入可以像传统模式销售所得一样客观，它不同于传统模式，以销售少量的明星产品负担起绝大部分的收益，长尾商业模式要求低库存成本以及强大的平台以保证小众商品能够及时被感兴趣的买家获得。

<center style="color:#C0C0C0;font-size:12px">图5-4  长尾商业模式</center>

#### 2、应用案例

在传统的图书出版行业，很多有抱负的作家都会花费大量的时间编写并提交手稿给出版社，盼着作品能够出版，但是往往不断被拒绝，因为传统的图书出版模式是建立在一套甄选流程上的，出版社审阅大量作家的手稿，并且从中选出最有可能创造庞大销量的作品，因此那些没有名气或者稍微逊色的作品都会被拒绝，因为排版、设计、印刷和销售这些卖得不好的书籍无法获利，出版社感兴趣的是那些可能拥有大量读者、可以大量印刷的作品。

在当下国内外有些图书出版行业已经发生了变革，它们改变了传统以畅销书为中心的初版模式，转而为任何有需要的人出版。它们的商业模式是基于帮助小众的、业余的作家把作品推向市场的目的，通过在线商城，向作家提供排版、印刷工具，并帮助他们推广作品的做法，消除了传统的准入门槛。这与传统模式下的选择有市场价值的作品大相径庭，以“用户发起的小众作品”形成了长尾模式，服务并连接了作家和读者两大群体，这一体系之所以可以行得通，是因为书籍只在订单产生的情况下才会被印刷出来，任何一个作品失败，对于出版方都近乎是零成本的。

### 2.3 多边平台商业模式

#### 1、概念

多边平台将两个或者更多独立但相互依存的客户群体连接在一起，这样的平台对于平台中某一群体的价值在于平台中其他客户群体的存在。平台通过促进不同群体间的互动而创造价值。一个多边平台的价值提升在于它所吸引的用户数量的增加，这种现象被成为网络效应。

多边平台经常会面临一个“先有鸡还是先有蛋的”两难困境，通常解决这个问题的一种方式就是向某一客户群体发放补贴或者免费，尽管一个平台的运营成本来自于向平台中的所有群体提供的服务，但运营者经常需要决定以低廉的或者免费的价值主张来吸引某一个群体加入平台，以达到吸引平台另一群体客户加入平台的目的。但这种方式仍然会面临一个困难，即要弄清楚多边平台哪一边是需要给予补贴的，如何以合适的价格吸引到他们。

<div class="essay-image"><img src="/assets/library/essays/business-model/image-20210225144332841.webp" alt="image-20210225144332841" loading="lazy" decoding="async" /></div>

<center style="color:#C0C0C0;font-size:12px">图5-6  多边平台商业模式</center>

#### 2、应用案例

百度商业模式的核心就是它的价值主张：在国内网络发布精准定位的广告。通过一项叫做百度推广的服务，广告商可以发布广告并将链接放进百度的搜索页面，当人们使用百度搜索引擎时，这些广告就呈现在搜索结果的旁边。百度要确保只有与搜索关键词相关的广告会呈现出来，这项服务对于广告商而言非常有吸引力，使得他们得以针对搜索内容和某一特殊人群量身打造在线广告，尽管该模式只在许多人都选择使用百度搜索引擎的前提下有效。越来越多的人用百度搜索，越多的广告将被呈现出来，为广告商创造的价值就越大。

百度对广告商的价值主张能否实现，很大程度上依赖于网站吸引到的用户数量，因此，百度为这个消费客户群体推出了强大的搜索引擎服务和日益增多的工具，为进一步拓展搜索功能，百度设计了一项新的服务，使得百度广告商的广告可以在第三方网站的网页上呈现，这项服务叫做百度联盟，第三方在自己的网站上发布来自百度的广告，并从百度的广告收益中分得一部分。百度联盟会自动地分析第三方的网站内容并为浏览者提供内容相关的文字和图像广告。百度将第三方网站的价值主张定位为百度的第三方客户群体，并帮助他们利用自己的网站内容赚钱。

作为一个多边平台，百度有着非常独特的收益模式。它从广告商这一客户群体中赚钱，对于另外两个客户群体——上网浏览者和内容提供者则给予补贴，这是非常合乎逻辑的，因为广告呈现给浏览者的次数越多，从广告商处赚取的收益就越多，反过来，增加的广告收入会鼓励更多的内容提供者者与百度联盟合作，广告商不会直接从百度购买广告，他们在第三方网站上与广告关键词相关的搜索词条或搜索内容竞价。竞价通过百度推广拍卖服务实现：越热门的关键词，广告商竞价成功就需要付出更高的价格。从而百度通过在百度推广服务中获得的大量收益使得百度有能力持续改进面对搜索引擎和百度联盟用户的免费服务。

### 2.4 免费商业模式

#### 1、概念

在免费商业模式中，至少有一个关键的客户群体是可以持续免费地享受服务的，不付费的客户所得到的财务支持来自商业模式中另外一个客户群体，从而使得免费提供成为可能。

能够免费获得一些东西永远是一种极具吸引力的价值主张，任何一个营销专家或经济学家都会肯定的说，对于价格为0的商品产生的需求要数倍于价格为1分钱或者其他定价的商品所产生的的需求。那么就一个体系而言，如何做到免费提供一些东西，而最终还是盈利的呢？让免费产品和服务在商业模式中可行，有如下几种方式：

- 免费+广告：基于多边平台的免费商品或服务
- 免费+增值：免费的基本服务，可选的增值服务
- 免费、诱饵+陷阱：采用钓鱼的方式，以一个免费或者很便宜的初始价格吸引客户，并引诱客户使其进入重复购买状态

**（1）免费+广告**

广告是一种实现免费供给的、成熟的收益来源，我们从电视、广播以及网络上看到这些广告，它们有的以最高深莫测的形式呈现，有的则以靶向广告形式呈现。在商业模式范畴中，基于广告的免费是多边平台商业模式的一种特殊类型。平台一边是以吸引用户为目的而设计内容、产品或服务，另一边则是产生收益的广告位购买者。

**（2）免费+增值**

免费增值代表了一个商业模式，主要是基于网络将免费的基础服务与付费的增值服务相结合。这种模式的特点是，大量的用户从免费的、无附加条件的服务中获益，其中的大多数人永远也不会变成付费用户，只有其中小一部分，通常不到全体用户的10%，会为增值服务付费。就是这么一小部分的付费用户补贴了免费用户，这种模式之所以成为可能的原因在于向免费用户提供的服务的边际成本很低；同时这个模式中有两个关键元素需要关注：免费用户的平均服务成本、免费用户向付费用户的转化率。

**（3）免费、诱饵+陷阱**

这种商业模式的特点是初期以低价或免费的价格提供有吸引力的商品，且该商品还将进一步地鼓励对相关产品或服务的不断消费。这一模式也被称作“招徕定价”，“招徕定价”是指初期以补贴价格甚至是亏本的价格提供商品，意图通过后续消费获得利润。

#### 2、应用案例：免费+广告

传统的报纸通过在书店、报刊通过低价销售获取收益，但是在当下网络信息时代，来自于报纸销售和广告收益已经很难维持报纸发行公司继续维持下去，其中有一部分报纸发行公司选择了改变发行模式，首先它的报纸是免费提供的，其次它的派发以在人群密集的办公去以及公共交通网点人工发放或自取，最后它的报纸编辑质量只要满足年轻的上班族通勤往返途中消磨时光就可以，这就消减了报纸的编辑成本；同时由于免费的形式，导致阅读报纸的用户数量快速增加，吸引了更多的广告商，同时增加了发行公司的议价能力。

#### 3、应用案例：免费+增值

软件产业有两个特点：第一，为保证有一批负责软件开发的工程师而支付高额的固定成本；第二，收益模式通常是销售多种基于用户的软件使用许可证以及软件的常规升级。

在美国有一家名叫红帽的软件公司彻底颠覆了这个行业，不再花费大量的人力、物力在软件研发上，而是将产品建立在开放源码的方式上，集结了数以千计来自于全球的软件工程师自愿产出的源码。红帽公司明白企业对耐用又可免费使用的开放源码感兴趣，但是因为没有任何实体对这些源码负责并提供维护而不愿使用，于是红帽公司填补了这个缺口，它免费提供稳定的、通过测试的、完整可使用的开放源码。红帽公司发布的每一条开放源码都享受7年的技术支持，客户从这种形式中获益，这使得他们可以享受开放软件源码带来的成本优势和稳定性能，同时还不用承担来源不明的软件产品带来的不确定性。红帽公司也能够从中获益，因为软件的核心由开放源码社区无偿的不断改进着，这就极大的降低了红帽公司的软件开发成本，同时它通过向企业收取会员费的形式，以便企业用户获得所有源码的使用权、服务支持及源码的法律保证。

#### 3、应用案例：免费、诱饵+陷阱

1904年，金·吉列首次向市场推出了可替换刀片的剃刀组合，他决定以大力度的折扣销售，甚至是在顾客购买其他产品的时候，免费搭送剃须刀柄，以期为他的可替换刀片创造需求。如今的吉列仍然在剃须产品中占领统治地位的品牌，这一模式的关键在于所提供的低价或免费的初始商品是否紧密连接后续消费品，企业可以从中获取较高的收益。控制这种“锁定关系”对该模式的成功至关重要，通过专利的保护，吉列保证竞争对手无法以更便宜的价格提供适用于吉列剃须刀的刀片。

### 2.5 开放商业模式

#### 1、概念

开放的商业模式适用于通过与外部合作伙伴系统地配合而创造和获取价值的企业。这种模式可以是“由外而内”地于企业内部尝试来自外部的理念，或者“由内而外”地向外部合作伙伴输出公司无用的理念或资产。

在一个以发散的知识为特征的世界中，组织可以通过将外部的知识、知识产品和产品整合进自身的创新流程，进而创造更大的价值并更好的利用自己的研发能力。反之，对某些企业而言，将无用的产品、技术、知识和知识产权通过同意许可、合资或者剥离的方式供给给外部团队使用，从而变现。

“由外而内”的创新发生于组织将来自外部的理念、技术、或者知识产权引入自身的发展和商业流程；“由内而外”的创新发生于当组织同意许可或出售其知识产权、技术或闲置资产。

**（1）由外而内**

拥有强势品牌、强大的分销渠道和良好客户关系的知名老字号公司，非常适合由外到内的开放的商业模式。这种方式可以让它们通过构建外部资源创新来挖掘现有客户关系的价值。

在内部投入大量精力进行研发的组织，通常产生许多无法实用化的知识、技术和智力资产。由于明确聚焦在核心业务上，一部分这些本来很有价值的智力资产闲置了下来，这种组织很适合采用由内到外的开放的商业模式。

## 三、一些常用方法和思路

### 3.1 客户洞察

#### 1、解释

企业一般都会在市场研究上投入重金，但它们最终设计产品、服务、商业模式的时候往往又会忽略客户的观点，要想设计好的商业模式，必须避免这类错误。我们必须通过客户的眼睛来观察商业模式，这样就有可能发现全新的机会，当然这并不意味着客户的思维是创新的唯一起点。但是我们必须强调，评估商业模式的时候，一定要考虑客户的观点。成功的创新有赖于对客户深入的理解，包括环境、日常工作、担忧和渴望。

其中一个难点在于对客户透彻的理解，商业模式的设计必须基于这份理解，在产品和服务设计领域，很多业界领先的企业都通过与社会学家一起合作来加深他们的理解；同时也有很多企业会安排员工会见客户、与销售团队交流、参观店铺等。但是，创新的真正挑战在于深入理解客户，而不是简单的去问他们要什么。

另外一个难点在于企业是否清楚需要关注哪些客户、忽略哪些客户。在很多情况下，能够拉动未来增长的那些客户往往并不是今天的金牛客户。因此，商业模式的创新不能仅仅聚焦现有客户群体，必须着眼于新客户群体。有很多成功的商业模式创新都恰恰满足了新客户未被满足的需求。

#### 2、方法：移情图

我们中很少有人能够享受到社会学家团队的专业服务，但任何人审视商业模式的时候都可以对其中涉及的客户群体简单画个像。移情图（“客户素描”）就是一个很好的工具，它能让你对客户的认知不仅仅止步于客户的人口统计学特征，让你更好的理解客户的环境、行为、担忧和渴望。这能让你设计出更有生命力的商业模式。因为一个好的客户画像能引导你设计出更好的价值主张，以更方便的方式接触到客户，同时采用更合适的客户关系类型。最终，它能让你更好的理解客户真正愿意花钱买什么。

### 3.2 创意构思

#### 1、解释

画出现有的商业模式是一回事，设计出一个新的创新的商业模式又是另外一回事。我们需要一个创造性的流程来产生大量的商业模式创意，并且能成功地识别出最佳的创意。这个流程就被成为构思。当需要我们设计出可行的新商业模式时，掌握构思的艺术就显得至关重要。

在传统观念中，绝大多数行业都会以一种主流商业模式为行为特征。但这项传统已经彻底改变了，如今我们在设计新的商业模式的时候会有更多的选择，同一个市场中会有不同的商业模式在相互竞争，而且行业之间的界限正变得模糊或者完全消失了。

当我们尝试创造新的商业模式的时候，我们面临的一项挑战就是要忽略现状并停止对操作性问题的担忧，这样我们才能产生真正新的创意。商业模式创新不是要回首过去，因为通过过去的事情很少能推测出未来可能的商业模式。商业模式创新也不是去看竞争对手，因为商业模式创新不是抄袭或对照标杆，而是创造新的机制来创造价值和获取回报。或者说商业模式创新是在挑战正统思维，设计出原创的模型，来满足那些未被满足的、新的或者隐藏在背后的客户需求。在找到新的或更好的创意之前，你必须梦想出一大堆创意，然后你才能从中挑出一个可实现的短名单。

#### 2、方法：选择焦点

商业模式创新的创意可以是不拘一格的，商业模式的九个模块的任何一个都可作为创新的起点。千变万化的商业模式创新会同时影响到多个模块，一般情况下，商业模式创新按照焦点分类，主要有：资源驱动、供给驱动、客户驱动、财务驱动。这4个焦点中任何一个都可以作为重大商业模式变革的起点，也都有力的影响商业模式中的其他8个模块，有些时候，商业模式创新可能会源自多个焦点。

| <span style="display:inline-block;width:120px">创新焦点</span> | 描述                                                   |
| :----------------------------------------------------------- | :----------------------------------------------------- |
| 资源驱动                                                     | 来源于组织现有的基础设施或合作伙伴资源                 |
| 供给驱动                                                     | 基于全新的价值主张创造                                 |
| 客户驱动                                                     | 基于客户需求、可获得性或便利性的提升                   |
| 财务驱动                                                     | 由新的收益来源、定价机制或者缩减的成本结构所驱动的创新 |

#### 3、方法：如果……会怎么样

受制于现状对思维的束缚，我们常常会苦于无法构思出创新的商业模式。现状遏制了想象力，克服这一问题的一个方法就是用“如果......会怎样”的问题来挑战传统假设。有了正确的商业模式原料，一些原本认为不可能的事情也可以成为能够做到的事情。“如果......会怎样”的问题帮助我们挣脱现有商业模式的束缚。他们能激发我们，挑战我们的思维，他们还能让更多新奇的、难于执行的主张闯入我们的思维。

询问“如果......会怎样”只能作为一个起点，这些问题会激发我们去发现使其中假设成立的商业模式。一些问题能找到正确的商业模式来实现，也存在一些问题可能会一直找不到答案，即使如此，也并不影响创意的产生。

### 3.3 视觉化思考

#### 1、解释

商业模式的讨论离不开视觉化思考，由于商业模式是由许多模块组成的复杂概念，而且模块之间又有复杂的关系，通过图片、草图、结构图和便利贴等视觉化工具来构建和讨论各模块将会让我们更好的理解一个新的商业模式。一旦团队将一个商业模式的草图画下来，团队就有了一个固定的东西来讨论，讨论也总能围绕核心内容。

#### 2、方法：使用便利贴

在讨论商业模式的时候，人们往往不会马上就哪些元素应该出现在商业模式画布中或者他们应该出现在哪个位置达成共识。每个人在思考商业模式的时候必须把便利贴放在手边，它是一个不可或缺的工具。很多的便利贴在一起就像是一个创意池，可以随意地添加、移除，以及在商业模式各模块之间挪动。使用便利贴也有一定的小技巧，尽量使用马克笔，同时保证一张便利贴上只包含一个元素。这样子做的原因是为了保证用很少的字来凸显关键词，避免信息过多，导致难以执行。

在使用便利贴呈现最终的商业模式前，也要同样关注讨论过程，参与者讨论在画布上贴上哪张纸、移除哪张纸、辩论元素之间互相的影响这一些行为，都让参与者能够深入理解该商业模式和它的动态变化过程，最终这些便利贴不仅代表了商业模式中的某个模块，也引导了战略讨论的方向。

#### 3、方法：使用草图

草图可能会比便利贴更为有效，因为人们对图像的反应要比文字强烈许多，图像更为直接的传递信息。既然是草图，大家不用过于担心自己的画图能力，这就类似于我们在画原型草图的概念一致，只要能够传达意思方便讨论即可。

### 3.4 讲故事

#### 1、解释

一般情况下，新的或者创新性的商业模式可能是难以描述和理解的，正如商业模式画布帮助你描绘和分析商业模式一样，讲故事有效的帮助你沟通这个模式的相关内容，好的故事能抓住听众，故事是一个理想的热身工具，为深度探讨商业模式及其内在逻辑做好准备。借助商业模式画布强大的解释能力，讲故事能让听众暂时放下对陌生事物的怀疑。

讲故事的目的是为了引人入胜、栩栩如生地介绍一个新的商业模式，尽可能的让故事简单，只设计一个故事主角，根据受众的不同，你可以设计不同视角的故事主角。

#### 2、方法

要讲述一个引人入胜的故事可以有很多种方法，每种方法都有优劣势，也都有各自适合的场景和听众。

| <span style="display:inline-block;width:120px">方式</span> | 描述                                                         | 适用场景                                       | <span style="display:inline-block;width:120px">时间与成本</span> |

## 四、商业模式设计流程

### 4.1 目的与动机

每一个商业模式设计项目都是独特的，有自己的挑战、障碍和关键的成功因素，任何组织开始意识到某项问题并进行商业模式创新的时候，可能是基于不同的动机和目的。

#### 1、目的

- 满足未被相应的现实市场需求
- 将新的技术、产品或服务推向市场
- 用更好的商业模式来改造颠覆现有市场或者推动其转型
- 创造一个全新的市场

#### 2、动机

- 当前商业模式的危机
- 为了适应环境的变化，调整、改进或者捍卫当前的商业模式
- 将新的技术、产品或服务推向市场
- 为未来做好准备，开发和验证最终可能取代当前商业模式的全新商业模式

### 4.2 阶段和流程

商业模式设计流程有五个阶段：动员、理解、设计、实施和管理。理解和设计阶段一般会并行，在理解阶段的早期就可以启动商业模式建模，简单地勾勒最初的商业模式创意；在设计阶段的建模可能会激发出新的创意，而这些创意有需要额外的研究，我们就再次回到理解阶段。最后阶段的管理，就是持续管理你的商业模式，在如今的商业氛围中，我们要清晰的认识到，任何商业模式的生命周期都不会太长，我们需要通过持续的管理和演进来延长它的生命，这个过程中需要我们不断决定哪些部分是有用的，哪些是过时的。

| <span style="display:inline-block;width:120px">阶段</span> | 目标                                             | <span style="display:inline-block;width:120px">焦点</span> | 描述                                                         |
| ---------------------------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------- | ------------------------------------------------------------ |
| 动员                                                       | 为组织成功的商业模式设计项目做准备               | 前期准备                                                   | 为成功的商业模式设计活动做充分的准备，让大家意识到需要新的商业模式，描述该项目背后的动机，建立一种统一的语言来描述、设计和分析讨论商业模式 |
| 理解                                                       | 研究和分析商业模式设计活动所需的元素             | 钻研                                                       | 商业模式设计团队完全沉淀到相关的知识里：客户、技术、环境。收集信息，访谈专家，研究潜在客户，还要识别需求和问题 |
| 设计                                                       | 创造并验证可行的商业模式方案，从中选择最优的方案 | 探究                                                       | 将前一个阶段的信息和创意转化为可被开发与验证的商业模式模型，在深度探究商业模式后，选择最满意的商业模式设计 |
| 实施                                                       | 实地实施选取的商业模式模型                       | 执行                                                       | 实施所选的商业模式设计                                       |
| 管理                                                       | 根据市场的反应调整和优化商业模式                 | 演进                                                       | 建立管理组织架构来持续的监控、评估、调整或改变你的商业模式   |

#### 1、动员阶段

第一阶段的主要活动是制定项目目标框架，验证最初的商业创意，做项目计划和组织团队。

组织团队是第一阶段的关键活动，为了保证接触到正确的人和信息，最好能够聚合各种管理背景和行业经验的人才，汇聚新鲜的创意、正确的人际网络，而且确保他们对商业模式创新的深度投入。

在动员阶段一个明显的风险就是人们通常会高估最初的商业模式创意的潜力，这不仅会导致思维的狭隘，也会限制其他可能性的探索。要缓解这方面的风险，可以邀请所有的参与者先头脑风暴一定时间，找出各种理由来证明为什么这个创意行不通，然后在头脑风暴一定时间，找出各种证据来证明为什么这个创意有前途。

在这个阶段，有一些事项需要额外注意：

**（1）项目合法性**

在组织运作的时候，建立项目的合法性是成功的一个关键因素，商业模式会影响到组织内部的各类人群，为了保证商业模式能够在组织内推动，最好一开始就让有威望的高层管理者能够参与进来。

**（2）管理既得利益**

小心识别和管理好组织内部的各种既得利益，组织内不是每个人对重新设计当前的商业模式感兴趣，因为有可能会威胁到某些人的利益。所以在最初一定要留意可能造成的影响，做好应对的准备。

**（3）跨职能团队**

理想的商业模式设计是有组织内各种类型的人组成的，包括不同的业务单元、业务职能、资历、专业技能等。他们站在组织内不同的视角，从而能够产生更好的创意，更加闭环的创意，增加项目成功的可能性。如果起初就能够在组织团队阶段涉及更多的职能部门，会在后续商业模式的推广中得到更多的认可。

#### 2、理解阶段

第二阶段需要对商业模式即将演进的背景环境建立良好的理解。商业模式的环境涉及很多内容，包括市场调研、研究客户、访谈相关领域专家、描绘竞争对手的商业模式。必须要沉浸到必要的材料和活动中去，对商业模式的设计空间建立起深刻的理解。

在这个阶段，有一些事项需要额外注意：

**（1）绘制/评估当前商业模式**

通常在组织内创新都是从当前的商业模式开始的，绘制和评估商业模式可以通过召开会议，在讨论当前商业模式的优劣势同时，还可以收集对于新商业模式的创意和观点的收集，为新的商业模式提供一手的创意。

**（2）不局限当前客户**

要找到新的商业模式，往往就要在更大的范围内搜索客户群体，不要仅限于现有的客户，未来的收益来源可以出现在任何地方。

#### 3、设计阶段

这个阶段的关键挑战在于创造和坚持大胆的新商业模式。为了能够产生突破性的创意，团队成员必须有能力在构思时舍弃现状，团队必须花时间探索多种创意，因为探索不同路径的过程本身就很可能产生最佳的可选方案。

为了避免过早的采用某些创意。在选择需要实施的新商业模式之前，可以验证不同的合作伙伴模式、寻找不一样的收益来源，还可以探索多种分销渠道的价值，这个过程中，可以使用不同的商业模式类型来探索和验证新的可能。

在这个阶段，有一些事项需要额外注意：

**（1）不要扼杀大胆的想法**

在组织内部通常有一种惯性思维，就是对大胆的创意、异想天开的想法进行打压，那么如何捍卫这些大胆的创意，找到一个平衡点就很关键。要取得这种微妙的平衡，可以为每个商业模式分析对应的风险、收益，找到每个模式中的不确定因素，然后找出能够在市场中快速验证的方法。

**（2）新旧模式关系**

设计过程中的一个大问题就是新的和旧的商业模式是应该独立运营还是整合为一个商业模式，可以通过业冲突合、利益冲突、成本结构等角度进行评估。

**（3）避免聚焦短期利益**

不要抱有第一年就获得很高的收入，在探索新的商业模式的时候，不要将视角仅仅放在当前，眼光要放长远，否则很有可能会错失未来增长的机会。

#### 4、实施阶段

一旦完成了商业模式设计，就要开始把它转化为一个能够被实施的设计，这包括定义相关的项目、设定项目里程碑、组织各种框架、制定详细的预算和项目路标等。这个过程中需要注意管理不确定因素，在商业模式实施过程中，需要密切的观察风险、回报的预期与实际的差距，要建立起应对机制，根据市场反馈迅速调整商业模式。

在这个阶段，有一些事项需要额外注意：

**（1）主动规避风险**

在商业模式实施之前，即在动员、理解、设计阶段，尽量保证内部人员全方位参与，这样在实施之前，除了可以获得认可以外，还能够尽早发现实施的障碍以及可能存在的担忧。

**（2）内部沟通**

组织内部可能会对新商业模式有一定的恐惧感，甚至是反感，在组织内部进行多次内部沟通活动，会将这种情况得到缓解，这个过程中可以使用图像、讲故事等有力的工具，帮助人们理解新的商业模式的逻辑和原理。

#### 5、管理阶段

对于一个组织而言，一个新的商业模式并不是直接搭建起来的，也不是一成不变的，这就意味着实施阶段后，还需要通过不断的评估商业模式和扫描环境来理解外部因素对商业模式的长期影响。这个过程中可以考虑通过定期的跨部门研讨会来评估商业模式，这样能够帮助我们判断是否需要对它进行微调或者彻底改造。同时我们也可以考虑通过管理一组商业模式来主动响应市场，这是因为在当前市场情况下，可能今天有效的商业模式转眼间就失去优势，这就类似于产品生命周期一样，我们需要思考适合未来市场的商业模式来代替现在仍然盈利的商业模式。

在这个阶段，有一些事项需要额外注意：

**（1）商业模式管理机制**

考虑建议一个商业模式管理的小组帮助企业内部管理各种商业模式，这个小组可以协调各种商业模式、与相关利益人互动、发起创新或重新设计商业模式以及跟踪组织现有商业模式演进过程，同时小组还需要处理好组织中各种商业模式协同的可能性及避免冲突。

**（2）商业模式组合**

一个组织内部可能存在多个项目，每个项目对应有不同的商业模式，所处的阶段也是不一致的，为了保证组织内各项目的正常推进，避免某一项目陷入危机，在内部最好建立起一个商业模式的组合，用当前挣钱的业务补贴那些面向未来的商业模式。
