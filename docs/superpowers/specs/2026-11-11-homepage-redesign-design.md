# 首页改造（方案 A）· 设计说明

日期：2026-11-11
状态：待确认

## 一、意图

现在的首页是 Firefly 默认的「全站文章卡片列表 + 分页」：读者进来看到的是一堆卡片，看不出这个站点在讲什么、该从哪儿读起。

改成一张**门户页**：第一屏讲清「我是谁、写什么、从哪开始」，往下按**判断的层级**把内容摊开（日报 → 精选 → 两本书 → 四个栏目 → 学习记录 → 作者）。参考稿：`outputs/shanfeng-firefly-design/home.html`（下称"参考稿"）。

## 二、目标 / 非目标 / 反目标

**目标**

1. 第一屏就能回答「这是谁、写什么、从哪开始」，不依赖滚动
2. 首页按内容层级组织，而不是按时间倒序
3. 与现有六个栏目（见山 / 增长 / 思路 / 调研 / 案例 / 笔记）形成入口关系
4. 保留一个轻量索引页，读者随时能找到全部文章

**非目标**

- 不重做导航、页脚、搜索
- 不改任何文章的 frontmatter、不动内容集合结构
- 不动合集页、书页、文章页

**反目标**

- 首页变成"什么都放一点"的信息堆
- 为了新首页改掉现有的颜色变量 / 暗色模式体系
- 首页出现需要手工维护的硬编码文章清单

## 三、约束

- Astro 7 + 现有 Firefly 结构；首页路由目前是 `src/pages/[...page].astro`（`PostPage` + 分页）
- 视觉沿用站点现有 CSS 变量（OKLCH 主题色、卡片、圆角、暗色），**不引入参考稿里的独立配色**
- 图片走 COS（`ASSETS_CDN_BASE`），新素材需上传；已有素材复用
- 部署策略不变：只本地提交

## 四、方案（已选 A）

| 方案 | 做法 | 取舍 |
|---|---|---|
| **A（选）** | `/` 换成落地页；新建 `/archive/` 年月索引 | 职责清晰，随时能删索引页 |
| B | 首页保留"最近更新"小节，不建索引 | 少一个页面，但早期文章没入口 |
| C | 直接搬参考稿 HTML | 快，但与内容集合脱钩，一周后难维护 |

方案 A 已确认。原 `[...page].astro` 的分页职责取消：`/` 只渲染首页，`/2/` 这类旧分页地址不再生成（若要保留兼容，可加 301 到 `/archive/`）。

## 六、索引页 `/archive/`

- 按年月倒序分组，每条只有「日期 + 标题」，点击进文章
- 不做卡片、不做分页、不做筛选
- 顶部一行说明 + 总数
- 若后续不需要，删掉这一个文件即可

## 七、实现要点

**新增文件**

- `src/components/pages/HomeLanding.astro`：首页主体（8 块里的 1–7）
- `src/styles/home-landing.css`：首页布局样式（复用现有变量）
- `src/pages/archive.astro`：索引页

**改动文件**

- `src/pages/[...page].astro`：第 1 页渲染 `HomeLanding`；其余页不再生成（改为只 `getStaticPaths` 出 `/`）
- 需要的话加一条 `_redirects` / `astro.config` 重定向 `/2/ → /archive/`

**样式策略**

- 只用现有 CSS 变量与 Tailwind 工具类，颜色不新增
- 参考稿的 `firefly-home.css` 只借用布局参数（栅格、间距、字号阶），不整段搬
- 暗色模式必须跟着现有 `dark:` 走

**性能**

- Hero 图 `fetchpriority="high"`，其余图片 `loading="lazy"`
- 首页不引入新的 JS 依赖；交互只有锚点跳转

## 八、验收

1. `/` 在 1440 / 1024 / 768 / 390 四个宽度无横向溢出、无文字截断
2. 暗色模式下所有区块可读，无"白块"
3. 首页不出现只有一页的分页控件
4. `/archive/` 能列出全部文章，按年月分组正确
5. 六个栏目入口链接可用（见山 / 增长 / 思路 / 调研 / 案例 / 笔记）
6. `astro build` 通过；页面数变化符合预期（少掉的分页页 ≈ 新增 archive 页）
